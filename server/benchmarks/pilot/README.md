# Exploratory runs

These 150–250 ms sequential runs guided implementation. They are not the final
alternating comparisons: use `../paired` for the retained changes and covering
index experiment. `06-counts.txt` measures the rejected trigger-based SQLite
counters; that variant is not in the final source. `06-index.txt` is an initial
index experiment, subsequently measured more carefully in `../paired/06-index*`.
